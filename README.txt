SXPAY REAL STORE V4
تسجيل المستخدم الحقيقي:
- الاسم
- اسم المستخدم
- البريد الإلكتروني
- رقم الهاتف
- كلمة المرور + التأكيد
- كلمة المرور تُخزّن Hash
- جلسة محفوظة 30 يومًا على نفس الجهاز/المتصفح عبر HttpOnly cookie
- السلة والطلبات مرتبطة بالمستخدم
- /account.html للحساب
- /admin لوحة الإدارة

تشغيل:
1) ثبّت Node.js
2) داخل المجلد: npm install
3) npm start
4) المتجر: http://localhost:3000
5) حساب المستخدم: http://localhost:3000/account.html
6) Admin: http://localhost:3000/admin

غيّر ADMIN_PASSWORD وJWT_SECRET في بيئة التشغيل قبل النشر.

- إضافة زر 👁️ لإظهار/إخفاء كلمة المرور وكلمة تأكيدها أثناء الكتابة.
